#How to run Backend

#Installation

Ensure that .NET is installed on the host machine

Check with `dotnet`, if it is installed then you should see usage information

If .NET is not installed, download it from Microsoft

Ensure that the Postgres driver is installed 

`dotnet add package Npgsql`

#Running the service

To start up the backend service, navigate to the backend project directory `ActiveArchive` and run `dotnet run`
