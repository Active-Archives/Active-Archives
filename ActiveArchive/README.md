# How to run Backend

## Installation

Ensure that .NET is installed on the host machine

Check with `dotnet`, if it is installed then you should see usage information in the terminal

If .NET is not installed, download it from [Microsoft](https://dotnet.microsoft.com/en-us/languages/csharp)

Ensure that the Postgres driver is installed 

`dotnet add package Npgsql`

## Running the service

To start up the backend service, navigate to the backend project directory `ActiveArchive` and use `dotnet run`
